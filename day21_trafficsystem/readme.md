This C program collects up to 30 vehicle records—including their ID, speed, and lane number—and analyzes them to detect speed and lane violations. A speed violation occurs when a vehicle exceeds 80 km/h, while a lane violation is identified when the vehicle’s ID modulo 4 does not match its assigned lane. The program also counts how many vehicles occupy each lane to determine the busiest and least busy lanes. Finally, it displays a detailed table showing each vehicle’s data along with violation indicators, followed by a summary of total violations and lane statistics.
